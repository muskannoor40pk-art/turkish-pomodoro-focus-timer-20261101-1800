## Overview
The Pomodoro Focus Timer is a lightweight, browser-based productivity tool tailored for the Turkish market. It helps users manage their time using the Pomodoro Technique, featuring a sleek circular progress indicator and customizable session durations. Perfect for students, developers, and professionals looking to maintain deep focus throughout the day.

## Features
*   **Circular Progress Ring:** Visual feedback for remaining time.
*   **Customizable Durations:** Easily adjust work and break intervals to fit your workflow.
*   **Session Statistics:** Track your completed focus sessions.
*   **Responsive Design:** Works seamlessly on desktop and mobile devices.
*   **Zero-Dependency:** Built with pure Vanilla JS for lightning-fast performance.
